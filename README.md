# 伴读

## 为什么做伴读

读书时走神，是一本书真正走进你脑子里的时刻。伴读想做的，是让你放心走远，也认得回来的路。

下面五个场景，是走神时现有工具接不住的地方。

| 场景 | 痛点 | 伴读的做法 |
|---|---|---|
| 读着读着想到别处：读到「机器学习是 AI 的一个子集」，想知道其他子集是什么 | 切出去搜，要重新交代背景，搜完回不到原处；不切出去，念头就丢了 | 选中一段就是划线，直接问。Claude 已经拿到书名、页码、划线和前后各约 500 字；书外的问题也照常答 |
| 读到有意思的内容，想找人聊 | 身边的人没读这本书，接不上话；通用聊天工具要你贴原文，也不知道你是做什么的 | `learner.md` 写着你的背景和手上的工作，讲解和「和我的工作有什么关系」都按它来；每本书一段对话，重开书回到上次读到的那页 |
| 一个问题牵出下一个：问完子集，又想问规则引擎和大模型怎么配合 | 越追问扯得越远，回头找不到原文，也找不到之前的讨论 | 同一段对话里连续追问；聊远了就开「新对话」，旧的收进「历史」；导读、导图里点出处跳到原文，点「回到第 N 页」一键回来 |
| 有疑问，但不知道怎么问 | 只会问「这段什么意思」，得到的也是泛泛的回答 | 划线后约 5 秒，给出三句可以直接发的问题：两句是你最可能问的，一句标「深一层」，追问前提、机制或边界；按 Tab 填进输入框，改了再发 |
| 读原文和看回答抢屏幕 | 读原文想两页并排，看长回答想要宽的回答栏，固定布局两头都别扭 | 拖中间的版心调宽度，放得下就双页，放不下自动变单页；双页时 Claude 同时看左右两页 |

## 它是什么

边读 PDF 边问 Claude 的桌面应用：选中一段即划线，右侧对话栏直接问；Claude 知道你在读哪本、第几页、划了什么、前后文是什么，再结合你的背景和工作来讲。

## 安装（一次）

需要 macOS、Chrome、已登录的 Claude Code（终端里能跑 `claude`），以及 Xcode 命令行工具（`xcode-select --install`，用来编译扫描页识别工具）。

1. 后台服务：`./install.sh`（登录即启动，挂了自动拉起；卸载用 `./install.sh --uninstall`）。
2. 用 Chrome 打开 `http://127.0.0.1:8770/`，点中间版心里的「安装到桌面」，在弹窗里点「安装」。之后「伴读」出现在启动台和「应用程序 / Chrome 应用」里，可以拖进程序坞。
3. 把 `learner.md` 改成你自己的背景和手上的工作。Claude 按它决定讲多深、用什么打比方，「和我的工作有什么关系」和划线预测也按它来。导读、导图、中英对照的提示词是按医学文献和医疗行业读者调的，读别的领域可以改 `server.py`、`features/guide.py`、`features/mindmap.py` 里的提示词。

## 使用

界面是一本摊开的「评点本」：左边是书页，中间一条版心放书架、中英对照、书名和页码，右边是 Claude 的批注栏。批注栏顶上的「Claude 看到」写着它此刻看到的那句划线；没划线时写「第 N 页整页」。

按住版心的空白处左右拖，调整书页和批注栏的宽度，宽度会记住。左边放得下两页（每页至少按原尺寸的 1.25 倍）时书页左右两页一排，往左拖到放不下就变成单页，拖回来又是两页；中英对照打开时始终单页。双页时没划线就提问，Claude 同时看到左右两页（批注栏写「Claude 看到 · 第 N、N+1 两页」，扫描版两页的原图都给它）；版心页码和读书进度记左页。

1. 打开「伴读」，点「添加书库文件夹」，选放 PDF 的文件夹，Chrome 问是否允许查看时选允许。只需一次，之后在搜索框按书名找。
2. 也可以把 PDF 拖进窗口，或在 Finder 里对 PDF 右键「打开方式 → 伴读」。
3. 读的时候选中一段就是划线，右侧直接问，或点「这段什么意思」「举个例子」「和我的工作有什么关系」。没划线时问的是当前页。
4. 每本书一个对话，换书自动切换。重新打开一本书会回到上次读到的页。
5. 「新对话」让 Claude 换一段新会话，刚才那段收进「历史」，不删；「历史」里按时间列出这本书的每段旧对话，点开只读。一段对话超过 20 轮会提醒开新的：Claude 每次回答都要把前面的对话从头读一遍，越长越慢。
6. 划线后提示条里有「撤销」；之后点一下任何一条划线，旁边出「删除这条划线」。

**划线后的输入预测**：每划一句，输入框上方会列出三句话（约 5 秒，按这句的前后文、你问过的话和 `learner.md` 猜）：前两句是你接下来最可能问的；第三句标着「深一层」，是你未必想得到、但真读懂这句要过的那一关（这句默认了什么、凭什么成立、什么时候不成立、哪里和前后文对不上）。当前那条同时以灰字显示在输入框里。按 Tab 把它填进输入框，可以接着改再发；↑↓ 换一条，点一下也能填；Esc 收起。不想用就直接打自己的字，预测会让开，输入框删空了又会回来。三条出现时占用快捷按钮那一行；没划线、没猜出来、问题发出去之后，快捷按钮照旧。每划一句调一次 Claude Sonnet，连着划时前一次会立刻停掉。

**框选和贴图**：图、表、公式选不中文字时，按住 ⌥ 在书页上拖一个框（或点版心的「框选」再拖），框里的内容连同那块区域的图片一起交给 Claude。也可以在输入框里 ⌘V 贴截图，一次提问最多附 6 张。

**「/」菜单**：在输入框打「/」弹出命令：「/导读」「/导图」打开对应的标签；`/learn`（按讲解加小测的方式教）、`/deep-reading-analyst`（深读分析）、`/grill-me`（追问我）是 Claude Code 的 skill，选中后接着写问题再发送。上下键选择，回车确认，Esc 关闭。

**导读**：批注栏顶上切到「导读」，点「生成导读」（只有点了才生成），约半分钟出一张卡：一句话讲这份材料说什么、从哪几页读起、几个关键问题。每条回答都带原文出处，点出处书页就跳到那几行并闪一下，页边留一道靛色旁线，书页底部出「回到第 N 页」；点「接着问」切到问答，Claude 看到的就是那句原文（不记成你的划线）。
- 论文、专家共识按全文出；书按你正在读的那一章出，「换一章」可以先看别的章；五页以内的短文档只给「速览」。
- 书签乱的扫描书（一页一个书签）点「从目录页建章节表」：识别前 30 页、找到目录、核对页码，约半分钟，一本书只建一次；页码对不上时会让你选。建不出来就自己填起止页。
- 生成过的按「书 + 范围」存下，再打开直接显示；生成时可以切去问答或换书，好了「导读」标签旁亮一个点。

**导图**：批注栏切到「导图」。论文按全文、书按你正在读的那一章出图：先用文档自己的目录搭骨架（没有目录时由 Claude 按内容提议分支），点「让 Claude 填要点」后一支一支长出来，每个要点挂着原文页码。
- 点节点，书页跳到那句原文；节点卡里「问 Claude」切到问答并让 Claude 看到那句。
- 自己改：双击或 F2 改名，Tab 加子节点，Enter 加同级，Delete 删除，拖到别的节点上换位置，⌘Z / ⇧⌘Z 撤销重做。你写的、改过、挪过的节点带「我」字印。
- 重新生成只替换 Claude 写的、你没动过的节点；你删掉的不会再冒出来；生成完不满意可以撤销回去。
- 节点旁的藤黄点表示那段原文你划过线，带外圈表示还问过 Claude；「卡」字印表示学习者档案里标了卡住的概念；靛色书签是你现在读到的位置。「全貌」收回一级，「读到处」回到正在读的地方。

**中英对照**：读英文时点中间版心里的「中英对照」，每段英文下面插一段中文译文，原文版式、图、表、公式都不动；双栏论文先排左栏再排右栏。只翻译你翻到的页和前后两页，一页大约 10 秒，译过的存缓存，翻回来立刻显示。对照模式下照样能划英文提问；选中中文译文提问时，Claude 会同时拿到这段的英文原文。译文由 Claude Sonnet 生成，术语按国内教材和指南的译法，关键术语后括注英文。

扫描版 PDF 翻到哪页就识别哪页（页面右上角显示「识别文字中…」，一页一两秒，识别过的页翻回来不用再等），之后和文字版一样能选中划线。识别会认错个别字（实测出现过 μg 认成 pg），Claude 同时拿到这一页的高清原图，涉及数字、公式、表格时以原图为准。

## 原理

| 环节 | 文件 |
|---|---|
| 书架：书库文件夹授权、PDF 清单、搜索、最近在读（句柄存 IndexedDB） | `web/library.js`、`web/db.js` |
| 阅读器：pdf.js 渲染，大文件按需分段读，选中即划线，同步阅读位置 | `web/reader.js` |
| 扫描页识别：macOS Vision 识别每行文字和位置，铺成透明文字层；结果按「书 + 页」缓存 | `tools/ocr.swift`（install.sh 编译成 `bin/ocr`）、`server.py` 的 `/api/ocr` |
| 中英对照：量出每行位置 → 找栏间距 → 分段 → 每段切成原图块，块下插译文；译文分组并行交给 Claude，逐段流回，按「书 + 页 + 段落内容」缓存 | `web/bilingual.js`、`server.py` 的 `/api/translate` |
| 对话栏：流式显示回答，每本书一个会话；回答里的图片和非 http(s) 链接按文字显示 | `web/chat.js` |
| 批注栏的标签（问答 · 导读 · 导图）、「/」菜单的动作登记表 | `web/panel.js`、`web/registry.js` |
| 框选和贴图：区域截图存进数据目录，作为附图交给 Claude | `web/region.js`、`features/region.py` |
| 「/」菜单：列出 Claude Code 命令和白名单里的 skill | `web/slash.js`、`features/commands.py` |
| 导读：本地判断文档类型和章范围，`claude -p` 按行写出导读，服务端逐条核对引句在原文里、回填页码，再推给页面 | `web/guide.js`、`features/guide.py` |
| 导图：书签或版式标题搭骨架，按分支调 `claude -p` 填要点并校验引句；Mind Elixir 5.15.1 渲染与编辑，存盘带版本号防两处同时改 | `web/mindmap.js`、`features/mindmap.py`、`web/vendor/mind-elixir/` |
| 安装到桌面、Finder 打开方式、服务没开时的提示页 | `web/app.js`、`web/manifest.webmanifest`、`web/sw.js` |
| 后台服务：接收划线与阅读位置，把提问转给 `claude -p`（只开放读文件和查资料的工具） | `server.py`，launchd `com.albert.reading-companion` |
| 提问时注入阅读上下文（书名、页码、划线及前后各约 500 字；扫描版附当前页图像） | `.claude/hooks/inject_reading.py`（UserPromptSubmit） |
| 回答后记日志 | `.claude/hooks/log_qa.py`（Stop）→ `data/log/日期.md` |
| 讲解规则、学习者档案、引入工作记忆 | `CLAUDE.md`、`learner.md` |

书由 Chrome 直接读，后台服务不碰外置盘：launchd 启动的进程读 `/Volumes` 会被 macOS 隐私权限（TCC）拦下。

## 数据（`data/`，不进 git）

- `log/YYYY-MM-DD.md`：每轮问答原文
- `chats.json`：各书当前这段对话与 Claude 会话 ID；`chat-archive/`：点「新对话」收起的旧对话，每本书一个文件
- `highlights.json`：各书划线
- `progress.json`：各书读到第几页
- `current.json`：此刻的阅读位置和最近一次划线
- `page.jpg`：扫描版当前页的高清图（2000 像素宽）
- `ocr/`：扫描页识别结果缓存
- `translate/`：中英对照译文缓存；`translate-work/` 是翻译时的空工作目录（不带伴读的 hook 和规则文件）
- `regions/`、`attachments/`：框选的区域图、贴进来的截图
- `guide/`：导读缓存（按书和范围）；`chapters/`：从目录页建的章节表
- `mindmap/`：各书的导图（含你的修改）和重新生成前的快照
- `claude-work/`：导读、导图调 Claude 时的空工作目录
- `server.log`：后台服务日志
